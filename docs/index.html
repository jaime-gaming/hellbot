📋 How this works

The bot writes its error and warning summary to docs/status.json on every heartbeat (default every 15 minutes). The JSON is pushed to the main branch and served by GitHub Pages.

If the status hasn’t updated in more than 2 heartbeats (>30 minutes), the bot may be offline or the push failed.

🔒 This page shows errors and warnings only. No full logs, no participant data, no tokens.
